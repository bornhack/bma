Fancy Options

The fancy options all load lots of markup and javascript. They require a modern browser to get the full effect. Fallbacks for noscript users are provided when possible.

Photoswipe

The photoswipe widget is full-featured with responsive image sizes, lightbox, large picture zooming and scrolling, slideshow, fullscreen, video and audio player, and file attribution and metadata. It also includes a fallback to a simple <img> tag for noscript users.

Plain HTML Options

The plain HTML options all load minimal markup, work without javascript, are accessible and should work with old browsers.

  • Uses a plain <img> element which is a link to the file detail page on BMA
  • Thumbnails are 50, 100, 150, 200, 300, or 400px wide. Sizes up to and including 200px has a double density 2x source included as well.
  • Thumbnail has aspect ratio 1/1, 4/3, 16/9, or 2/3
  • Thumbnail element includes file attribution and basic EXIF metadata in title as well as alt text
  • Thumbnail links back to the file on BMA
