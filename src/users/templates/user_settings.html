BMA Profile

Your profile contains the public setting for your BMA account. You can edit some of the values in it here.

Handle {{ user.handle }}  Update Your handle is a unique identifier for your BMA account. You can change it to anything you want, as long as the handle you want isn't already taken by another user. NOTE: Changing the handle will break URLs using it. The handle can only contain letters, numbers, hyphens (-) and underscores (_).
Display Name {{ user.display_name }}  Update The display name is shown instead of the handle whenever your user is mentioned somewhere on the site. It can be changed to any string up to 100 characters including unicode, emojis and so on. Display names do not have to be unique, so the same display name can be used by multiple users.
Description {{ user.description|default:"N/A" }}  Update A description of yourself which is shown on your profile page. Optional. Supports markdown. Sortof.
